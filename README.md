# LobbyTeam by SophiMind

> **One digital team for every way customers reach you.**

LobbyTeam answers phone calls, responds to emails and chats, calls back when a conversation needs a voice, and routes to the right human when that is the best next step. Behind every interaction, coordinated agents interpret the request, apply tenant business rules, and guide the customer toward a useful outcome.

---

## Design System & Architecture

- **Visual Language:** Apple High-Contrast Daylight × Cal.com Architectural Grid.
- **Color System:** 
  - Canvas: `#F5F5F7`
  - Cards: `#FFFFFF` & Frosted Glass (`rgba(255, 255, 255, 0.78)` with `backdrop-filter: blur(24px)`)
  - Ink: Primary `#1D1D1F`, Muted `#6E6E73`
  - Hairlines: `1px solid #E5E5EA` with crosshair `+` intersections
  - Pulse / Live Status: Signal Emerald (`#10B981` / `#34C759`)
- **Centerpiece:** The Magnetic Glass Switchboard — native coded SVG + Framer Motion interactive pipeline with real-time beam pulses, coordinated agent pucks (Understand, Act, Route), and warm human handoffs (Derek Hastings dossier).
- **Responsive Engineering:** Dedicated desktop (horizontal 3-zone switchboard) and mobile (vertical animated pipeline) views.

---

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Motion:** Framer Motion
- **Icons:** Lucide React

## Getting Started

```bash
# Clone the repository
git clone https://github.com/utk4l/lobbyteam.git

# Navigate to project folder
cd lobbyteam

# Install dependencies
npm install

# Start development server
npm run dev
```
